1 · Principles

♻️ Reuse before build
Lean on ECC agents + stdlib; write only repo-specific glue (Ponytail).
🛟 Degrade safe
Local checks never block on infra failure; CI is the hard backstop.
🪞 Local mirrors CI
quality:gate runs the same command locally and in CI — no drift.
📜 architecture.md wins
One source of truth resolves every contradiction.
🧾 Events are truth
If it's not in the event log, it didn't happen. Append-only.
🔪 Vertical slices
End-to-end, never horizontal layers.

Merges, flips enforce_admins, runs migrations. Final authority.
